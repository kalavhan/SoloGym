# Retired runtime screen plates

These files previously lived under `app/Assets/SoloGym/Resources/<folder>/<filename>`.
They are retained unchanged here for provenance and historical comparisons. They are no longer loaded by the app or included as Resources in player builds. Historical reports/manifests mentioning the old resource paths describe the earlier implementation; the corresponding bytes now live here.

The immutable approved targets remain in `design/renders`. The replacement runtime architecture uses independent background, logo, illustration and icon assets with code-drawn frames/controls. See `docs/engineering/layered-ui-and-avatar-implementation.md`.
