# Individual asset references — R3

One asset per image. This pack replaces the four-fit sheets as generation input.

- 8 separate top/vest images: male and female slim, medium, overweight, muscular.
- 8 separate shorts images for the same body set.
- 1 gloves-pair image, 1 boots-pair image, 1 headband image, 1 backpack image.
- One written reference TXT per asset, plus the 8 unchanged body fitting PNGs.

Use index.html to select and download an exact image and its matching brief.
The images contain no comparison grid or size labels. Gloves and boots are
paired equipment items; the pair remains together in one reference.
The backpack shows one product view, not two views on one sheet.

These are visual references for asset creation, not validated game overlays.
The final asset still needs transparency, body alignment and any required
layer separation. A body fitting export should use the body's 1024x1024 canvas.
Current reference images retain their native generated dimensions; their size
is not an assertion of body registration.

The standalone clothing and backpack renders were isolated using built-in
imagegen edits of the R2 reference sheets. They are not pixel-exact mechanical
crops. Exact edit prompts and source paths are in manifest.json and prompts/.
The existing gloves, boots and headband renders were copied unchanged.

17 built-in imagegen calls; no AutoSprite calls or credits. Runtime art and all
approved body/hair sources are unchanged. No new body or dressed character was
created. R2 remains archived separately; no contact sheets are included here.

## AutoSprite description limit
Use the short text under AutoSprite asset description and its dedicated copy button. All 20 descriptions are at most 174 characters, below the 200-character limit. Plain TXT copies are in descriptions/. The expandable detailed art brief is separate and must not be pasted into the asset description field.
