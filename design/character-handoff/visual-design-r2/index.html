What changes between builds

Slim: narrow shoulders, waist and hips.
Medium: moderate volume and relaxed drape.
Overweight: full rounded abdomen, reduced waist taper and cloth folds that show belly volume.
Muscular: broader shoulders, tapered waist and room for thighs.

Using AutoSprite

Its Asset Library documents uploading an image; the Assets API distinguishes upload from text generation. An upload saves your image as an asset source. It does not automatically fit clothing to the body.

For image-guided generation, attach the design and wearer references and request only the selected item. That redraw capability has not been verified in your UI here. For direct upload, isolate the selected garment and remove labels/background first; do not save a four-cut sheet as one equipment asset.

After generation, compare the exact collar, panels, trim and silhouette with the reference and check fit on the body. Image input reduces guesswork; it does not guarantee exact reproduction.
