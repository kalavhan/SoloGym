# Hanging punching bag — Home prop R1

One isolated hook, connected suspension chains and oxblood leather bag assembly.
Built-in imagegen authored the reference from the approved Home concept;
AutoSprite MCP saved it and produced the transparent export. AutoSprite did not
generate or redesign the artwork. One imagegen call; **1 AutoSprite credit**
for background removal. See [provenance.json](provenance.json) for asset ID,
timestamp and original/export hashes.

The original already includes alpha despite the requested white backdrop.
Both original and returned alpha are preserved without local image edits.
The AutoSprite derivative retains source RGB. Dark RGB outside the object is
under transparent pixels and is not a painted background in Unity.
Runtime Base.png is byte-identical to transparent.png.

The full 1024×1536 canvas is imported as one point-filtered uncompressed sprite.
Top hook pivot is (512, 17) in top-left source coordinates. Source scale and room
placement are provisional; the user will make a manual alignment pass after
room items are present. The occupancy quadrilateral describes the hanging
assembly, not a floor collider. No swing animation or character changes.

See the [single-object handoff](../../../../design/fantasy-home-bag-r1/index.html)
and [component notes](../../../../docs/design/pixel-home-bag.md).
Visual approval and device testing remain pending.
